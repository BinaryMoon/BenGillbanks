For a long time I have wanted to make a simple game creation tool that anyone can use to make and share games. In April 2025 I finally launched BeepMini, a place to make and play video games. It includes an open-source JavaScript game library and games made with the library, plus a browser based game editor for making adventure games. I plan to make other types of game editors in the future too.
